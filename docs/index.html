Financial News, Decoded

An AI agent that turns daily financial news into mechanism-level explanations and a growing concept library — so you learn how markets work, not just what happened.

Try it live → View code →

The problem

Financial headlines tell you what moved. They rarely explain why — and almost never connect today's story to the concept underneath it. Finews reads the news for you and rebuilds the mechanism, so each story leaves you with a concept you keep.

How it works

01

Fetch

Pulls fresh stories from financial RSS feeds (CNBC and more).

02

Decode

An LLM agent breaks each story into a plain-English mechanism, what's still uncertain, and the concepts underneath.

03

Build

Concepts accumulate into a personal library you can browse and revisit.

What I built

I scoped this product around concept-building over headline-chasing, designed the agent pipeline (RSS → LLM decode → concept extraction), and shipped the full app end-to-end on Next.js, Vercel, and Supabase.

Built with

Next.js 16 · React 19 · Tailwind 4 · Prisma + Postgres (Supabase) · OpenAI-compatible LLM (DeepSeek)
