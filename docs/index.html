问题

财经新闻只告诉你什么在动,很少讲为什么,更不会把今天这条新闻和它背后的概念连起来。Gist 替你读新闻、重建机制,让每条新闻最后都给你留下一个能积累的概念。

怎么运作

01

抓取

从财经 RSS 源(CNBC 等)抓取最新新闻。

02

拆解

一个 LLM agent 把每条新闻拆成大白话的机制、还不确定的地方,以及背后的概念。

03

积累

概念不断沉淀成一个可以浏览、回看的个人概念库。

我做了什么

我把产品定位在"积累概念"而非"追热点",设计了 agent 的处理链路(RSS → LLM 拆解 → 概念抽取),并把整个应用从 0 端到端做到上线(Next.js、Vercel、Supabase)。还针对生成等待做了体验优化:并行抓取与生成、精简 agent 轮次,提交后用骨架屏 + 分阶段状态提示替代长时白屏。

技术栈

Next.js 16 · React 19 · Tailwind 4 · Prisma + Postgres(Supabase) · OpenAI 兼容接口(DeepSeek)
